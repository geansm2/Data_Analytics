#  Data Analytics Portfolio

Este repositório contém uma coleção de análises de dados desenvolvidas para desafios técnicos e testes de processos seletivos. O objetivo é demonstrar habilidades em **Data Scraping**, **ETL**, **Exploratory Data Analysis (EDA)** e **Storytelling**.

---

##  Projetos e Desafios

### 1.  Análise de Mercado de Telecom (Cappta)
**Arquivo:** `Cappta_Gean_Machado.ipynb`  
**Descrição:** Estudo da penetração de planos móveis pós-pagos em relação ao IDH dos municípios brasileiros.
- **Técnicas:** Web Scraping (Pandas `read_html`), extração de dados do IDH (UNDP) e dados da Teleco.
- **Destaque:** Correlação entre desenvolvimento humano e consumo de tecnologia.

### 2.  Inteligência de E-commerce (Meliuz)
**Arquivo:** `Meliuz_Gean_Machado.ipynb`  
**Descrição:** Análise de performance de parceiros e conversão de vendas usando BigQuery.
- **Técnicas:** SQL via `pandas-gbq`, análise de séries temporais e cálculo de métricas de conversão.
- **Destaque:** Resolução de problemas de negócio com foco em crescimento orgânico.

### 3.  Data Modeling de Filmes (Solvimm)
**Arquivo:** `Solvimm_Gean_Machado.ipynb`  
**Descrição:** Processamento de grandes datasets de avaliações de filmes (estilo Netflix Prize).
- **Técnicas:** Manipulação de strings complexas, merge de datasets volumosos e agregação de ratings.
- **Destaque:** Engenharia de atributos e limpeza de dados não estruturados.

---

##  Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Bibliotecas:** 
  - `Pandas`: Manipulação e análise de dados.
  - `Matplotlib` & `Seaborn`: Visualização de dados.
  - `BigQuery`: Consultas em escala.
  - `BeautifulSoup` / `urllib`: Web Scraping.
